# Esrakuşumm — düzenlenmiş kaynak kod

Bu sürümde HTML/CSS/JavaScript ayrıştırıldı; kullanıcıya görünen içerik, medya sırası ve etkileşim algoritması korunmuştur.

- `index.html`: sahne ve galeri bileşenleri
- `styles.css`: görsel tasarım, mobil uyum, animasyonlar
- `app.js`: kaydırma, mum söndürme, hediye açma, galeri ve final
- `assets/`: iki arka plan görseli (orijinal gömülü görsellerden çıkarıldı)
- `media/`: fotoğraflar, videolar ve posterler

## Çalıştırma

```bash
cd esrakusumm_okunabilir_v16
python3 -m http.server 5500
```

Ardından `http://localhost:5500` adresini aç. Web fontları için internet bağlantısı gerekir.
